# Small Business License: Internal Staff Manual

**Confidential - Internal Use Only**

## Overview
This manual provides guidance to municipal officers processing Small Business License applications.

## Edge Cases
- If an applicant's ID is expired by less than 30 days, accept it conditionally and request a valid ID prior to final approval.
- If the address on the application does not match the ID, request a recent utility bill (within 60 days) as proof of residency.

## System Entry
Always verify the applicant's existing profile in the CRM before creating a new record to avoid duplicates.
